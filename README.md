# 🥐 Bakery Website — Collaborative Frontend Project

## 📌 პროექტის შესახებ (About the Project)
ეს არის საცხობის (Bakery) ვებგვერდის ფრონტ-ენდ პროექტი, რომელიც შექმნილია Figma-ში მოცემული UI დიზაინის მიხედვით. პროექტი მოიცავს სრულყოფილ სტრუქტურას: ნავიგაციას, მთავარ ბანერს (Hero), კომპანიის ისტორიას, პროდუქციის მენიუს, მომხმარებელთა შეფასებებსა და ფუტერს.

## 🎯 პროექტის მიზანი (Project Purpose)
პროექტის მთავარი მიზანია არა მხოლოდ სემანტიკური და ადაპტური (Responsive) ვებგვერდის აწყობა, არამედ **რეალურ გუნდურ გარემოში მუშაობის პრაქტიკული გამოცდილების მიღება**:
* Git-ისა და GitHub-ის გუნდური სამუშაო პროცესის (Workflow) დაცვა;
* ცალკეულ Branch-ებზე მუშაობა და Pull Request-ების მართვა;
* Code Review-ს კულტურის დანერგვა და ერთმანეთის კოდის შემოწმება;
* Merge Conflict-ების დამოუკიდებლად და შეთანხმებულად მოგვარება.

## 🛠️ გამოყენებული ტექნოლოგიები (Tech Stack)
* **HTML5** — სემანტიკური სტრუქტურისთვის
* **CSS3** — ვიზუალური გაფორმებისა და განლაგებისთვის (Flexbox, Grid, CSS Variables)
* **Git & GitHub** — ვერსიების კონტროლისა და გუნდური კოლაბორაციისთვის
